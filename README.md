# Jepret

Screen capture & recording untuk Windows yang ringan — fullscreen, region, last region, scroll capture, rekam layar + audio, editor sederhana, galeri riwayat, dan workflow per hotkey (save → clipboard → editor → buka di aplikasi lain).

> Status: kerangka (v0). Lihat [PRD.md](PRD.md) dan [TASKS.md](TASKS.md).

## Build
```powershell
cargo build --release -p jepret-app
# hasil: target\release\jepret.exe
```
